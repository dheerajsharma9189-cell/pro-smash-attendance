# Pro Smash Attendance

Attendance register for Pro Smash Badminton Academy: daily P/A by batch, month register, and WhatsApp reports for parents and batch groups.

**Open the app:** https://dheerajsharma9189-cell.github.io/pro-smash-attendance/

- Every phone asks for the academy's 4-digit PIN when the app opens.
- Shared register: all staff phones see the same attendance, saved in a Google Sheet on the owner's Gmail. The owner sets it up once from inside the app (it uses `setup/Code.gs`).
- Works offline: changes wait on the phone and save online when the internet is back.

This repository holds only the app's code. Student names, phone numbers and attendance are never stored here.
